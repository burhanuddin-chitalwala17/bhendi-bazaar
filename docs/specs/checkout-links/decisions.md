| Q4 | Where does opening a link add its items, given the cart lives on the buyer's device (`src/store/cartStore.ts`) and a guest has no server cart? (departs from TRD D3) | `/c/<shop>/<token>` is a page: it resolves the link on the server (edited → the shop's page, expired → the first product's page with the line) and otherwise renders checkout's skeleton while `POST /api/checkout-links/open` returns today's lines and the device adds them, marked, then opens checkout. The once-only claim is `CheckoutLinkOpen(linkId, cartKey)` with `cartKey` `user:<id>` or `device:<id>` (an httpOnly `bb_device` cookie), not a server cart id. The rate limit sits on the open request (`link` policy, per account or address), and the page is not in `EXTERNALLY_CALLED`, which lists route handlers only. A refused or failed open goes to the shop's page. The page itself is not rate-limited: it only says whether a 128-bit token exists, a search no budget changes. What was left out is not carried to checkout: unit 2 recomputes it from the link's stored items against the lines marked with it | Claude · reversible | 2026-11-25 | A route handler cannot write the device cart, and writing the signed-in server cart behind the device's back would conflict with its version and reach a guest not at all. was: TRD D3 "one transaction adds the items to the buyer's cart (guest cookie or account)" | implemented (unit 1) |
| Q5 | What does a link add for an item that is in stock but not at the asked quantity, or already in the cart? | Not at the asked quantity → left out and named, like an item out of stock (the check `/api/products/check-stock` makes). Already in the cart → the line keeps the larger quantity and takes the link's mark, never doubled | Claude · reversible | 2026-11-25 | The spec names only out-of-stock; one rule for both, and no silent quantity change. Taking the larger quantity keeps a second device or a sign-in from adding the link twice | implemented (unit 1) |
| Q6 | An expired link for several products opens which page? | The first product still on sale, with the expired line; none on sale → the shop's page | Claude · reversible | 2026-11-25 | A redirect opens one page; the first item is the one the chat was about | implemented (unit 1) |
