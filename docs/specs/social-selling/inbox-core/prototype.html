Shop Inbox

Prototype for three subfeatures of social-selling: inbox-core (the shared inbox, built on a fake source), inbox-instagram (DMs and comments) and inbox-whatsapp (chats). Phone width first. Each row is one journey, left to right; the first card is the step before it. Every string is the one that ships (ux.md).
