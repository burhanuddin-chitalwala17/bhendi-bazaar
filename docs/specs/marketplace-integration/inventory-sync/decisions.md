| Q26 | How does the order check stay cheap as shops join? | It is a safety net, every **ten** minutes: a change made on Bhendi Bazaar already pushes at once (Q19), so the check only catches sales made on a marketplace. A quiet run is two statements for one shop or thousands; only an expiring token takes the locked renewal (about hourly per shop on Amazon). One shop's failure (its marketplace, or its stored token) leaves the others checked and its own cursor where it was; a cursor is written only if it has not moved since the claim. Instant notifications (parent Q34) remain the step past a few hundred shops | implemented |
