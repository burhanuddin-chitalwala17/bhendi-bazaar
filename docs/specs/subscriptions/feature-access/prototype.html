Paid feature locks

Phone width (about 360px), the app's own colours and type. Three locks: Channels, Storefront, Image enhancement. Each row is one journey, starting from the step before it. Screens never lock; actions do. Every tab opens so the shop sees what it is missing; each paid action carries a lock and explains itself on tap, from every place it appears.

Channels

On⇄ admin switch ⇄Off

Off: no connect, publish, sync, reads or feeds. Live listings stay up, unsynced. The product form is unchanged.

Storefront

On⇄Off

Off: the team previews it as it is; everyone else sees "not yet available". Hidden from directory, sitemap, Sold by, search.

Image enhancement

On⇄Off

Off: no new enhancements. Work already queued finishes.
