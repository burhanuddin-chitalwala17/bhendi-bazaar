# ADR-0022: Every design axis goes through tokens, not just colour

- **Date:** 2026-08-30
- **Status:** Accepted
- **Context:** Colour had been governed since PR-33: semantic tokens in `src/app/globals.css`, a `.portal` scope that re-skins the whole admin surface without touching a component, and `tests/unit/design-tokens.test.ts` refusing a raw palette class anywhere in `src/`. A rebrand of colour was a one-file edit and had stayed one.

  No other axis had any of that, and a redesign is mostly the other axes. Type size was 86 arbitrary `text-[…]` literals spread over six sizes — `0.65rem`, `0.6875rem` and `0.7rem` are 10.4px, 11px and 11.2px, three spellings of one intention. Letter-spacing was 78 literals over nine values between `0.12em` and `0.35em`, across 32 files, all of them the same tracked-out uppercase eyebrow. Elevation was 18 raw Tailwind shadows with no notion of what a shadow *meant*. Page width was eight different `mx-auto max-w-*` literals, and the portal page title was eight verbatim copies of one `<h1>`. Shape was the exception that proved the rule: `--radius-lg` and friends already derived from `--radius`, so radius moved as one — but nothing recorded which step a card takes and which an input takes, and `select` and `input` had already drifted 2px apart.

  Two live defects fell out of the same gap. `--font-mono` was aliased to `var(--font-heading)`, so the twelve places rendering SKUs, order codes and payment ids drew identifiers in Playfair Display. And `--font-heading` was set by `next/font` but never registered as a theme token, so `font-heading` — present in twenty files, including every page title — generated **no CSS at all** and every heading silently rendered in the body face. A class that does nothing is worse than a wrong one: it reads as applied.

  The asymmetry is the point. A rebrand cost one file; a redesign cost more than a hundred. Whichever axis is ungoverned is the one that decides the cost of change.
- **Decision:**
  1. **Every design axis is a token, on the same terms colour already was.** `globals.css` gains a type scale below `text-xs` (`--text-2xs/3xs/4xs`, where the 3-up phone tile of [ADR-0016](0016-mobile-app-shell.md) lives), four tracking steps (`--tracking-label`, `-eyebrow`, `-eyebrow-wide`, `-display`), four elevation *roles* (`--shadow-raised`, `-lifted`, `-overlay`, `-inset-field`), two semantic shape steps (`--radius-card`, `--radius-field`), and one storefront column width (`--container-page`).
  2. **Elevation is named for what a thing is, not how big its shadow is.** Tailwind's scale answers "how big"; a redesign changes "what is this". `src/components/ui/` is the only consumer that matters — pointing the primitives at the roles is what makes the change one edit.
  3. **The type steps carry size and nothing else.** The literals they replaced set `font-size` alone, so pairing a line-height here would have silently reflowed ninety call sites. Leading stays an explicit `leading-*` decision.
  4. **`PageShell` and `PageHeader` (`src/components/shared/page-shell.tsx`) own page width and the page title.** Widths are named for the page's job — `narrow`, `form`, `default`, `wide` — not its pixel count, so they can move together.
  5. **A third party's colour is not ours to theme.** Facebook blue is Facebook blue in either mode, so `src/lib/social-brand.ts` holds those hexes — in one module, like `category-accent.ts`, rather than at the call site.
  6. **The test enforces every axis, and additionally proves that font utilities resolve.** `tests/unit/design-tokens.test.ts` refuses arbitrary sizes, arbitrary tracking, raw hex, raw Tailwind shadows and ad-hoc page containers, and fails on any `font-*` class with no matching `--font-*` theme token — the check that would have caught `font-heading` the day it was written.
- **Alternatives considered:**
  - *Adopt a block library (shadcn blocks, Magic UI) and restyle from there* — the obvious answer, and rejected as exactly backwards. Pasted blocks arrive as literals. Doing this first would have added to the 86 and the 78 rather than replacing them, and the next redesign would have cost more than this one, not less.
  - *Leave type and tracking as literals and rely on review* — what was already happening. It produced nine spellings of one eyebrow across 32 files. A rule people must remember is not a control; the colour rule held precisely because a test enforced it.
  - *Pair line-heights with the new type steps, as Tailwind's own scale does* — rejected for this change, not on the merits. It is the right end state and a deliberate design act; smuggling it into a mechanical migration would have moved ninety call sites under cover of a refactor.
  - *Collapse the sub-`xs` sizes to one step* — tempting, and wrong here. Three of the four are genuinely distinct on a 105px tile. Merging them is a redesign decision, and the token layer exists so that decision can be made later in one place.
  - *Rename the `next/font` variables to something neutral and keep `--font-mono` pointing at the display face* — rejected: `font-mono` is used for identifiers, and identifiers want a mono stack. The alias was a mistake, not a convention.
- **Consequences:**
  - ✅ A redesign of type, rhythm, shape or elevation is an edit to `globals.css` plus `src/components/ui/`, the same shape the colour rebrand already had. 182 call-site literals became 15 tokens.
  - ✅ Headings render in Playfair Display, which is what twenty files had been asking for and not getting; identifiers render in a mono stack.
  - ✅ A dead utility class now fails the suite instead of looking applied.
  - ⚠️ **Visible changes shipped with this.** Headings change face. Page titles on the four offer pages and `/org/new` move to the shared `text-3xl` treatment from their own `text-2xl`/`text-3xl font-bold`. `select` and `multi-select` corners move 2px to match `input`. Dialog and alert corners move 4px to the card step. Each is a drift this ADR exists to remove; none is a redesign, and all are now one edit to revisit.
  - ⚠️ Four sub-`xs` type steps is a denser scale than a designed system would choose. Recorded deliberately: the migration preserved what was there, and rationalising the scale is now a one-file change rather than an eighty-six-site one.
